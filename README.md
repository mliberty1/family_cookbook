# Family Cookbook

A Flask-based web application for managing and sharing family recipes with version history, user management, and full-text search.

## Features

- **Recipe Management**: Create, edit, and view recipes with full version history
- **User Authentication**: Token-based passwordless authentication (magic links)
- **Admin Panel**: User management, email invitations, and database backups
- **Search**: Full-text search across recipes, ingredients, and authors
- **Version History**: Never lose data - all recipe edits are preserved
- **Recipe Scaling**: Automatically scale ingredient quantities
- **Print-Friendly**: Clean print layouts for recipes
- **JSON-LD Support**: Preserves complete Schema.org Recipe format

## Quick Start

### Local Development

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Initialize database** (if not already done):
   ```bash
   python init_database.py
   python import_recipes.py
   ```

3. **Run the application**:
   ```bash
   python app.py
   ```

4. **Access the app**:
   - Open: http://localhost:5000
   - Login with admin user (token shown in init_database.py output)

### Database

The application uses SQLite with:
- Users and token-based authentication
- Recipes with complete version history
- Full-text search (FTS5)
- Normalized ingredients and instructions

Database file: `cookbook.db`

## Admin Panel

Admins can:
- Add and manage users
- Send email invitations via Mailgun
- Toggle user active/inactive status
- Grant/revoke admin permissions
- Download SQL database backups

Access at: `/admin` (requires admin login)

## Recipe Format

Recipes use the Schema.org Recipe JSON-LD format with custom extensions:

- **Ingredient sections**: Lines starting with "## " denote section headers
- **Notes**: Instructions starting with "🛈 " are displayed as notes

Example:
```json
{
  "@type": "Recipe",
  "name": "Chocolate Chip Cookies",
  "recipeIngredient": [
    "## Dry Ingredients",
    "2 cups flour",
    "1 tsp baking soda",
    "## Wet Ingredients",
    "1 cup butter",
    "2 eggs"
  ],
  "recipeInstructions": [
    "Mix dry ingredients",
    "🛈 Make sure butter is softened",
    "Combine wet and dry ingredients"
  ]
}
```

## Development

### Adding Features

The Flask app follows a simple structure:
- Routes in `app.py`
- Templates in `templates/`
- Static files in `static/`
- Database queries use the `query_db()` helper

### Database Migrations

To modify the schema:
1. Edit `schema.sql`
2. Test locally by recreating `cookbook.db`
3. On production, manually update via SQL or recreate database
